# This is a AI Resume Scanner
## AI Resume Scanner

### 🚀 Smart Resume Analysis & Skill Matching Platform

An AI-powered Resume Screening Web Application built using Python and Flask. It automatically extracts candidate information from PDF resumes, identifies technical skills, and evaluates skill matches to make the recruitment process faster and easier.

### 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- Machine Learning
- PyPDF2

### ✨ Key Features
- Upload resumes in PDF format.
- Extract candidate information automatically.
- Identify technical skills.
- Analyze resume skill matches.
- Display matching and missing skills.
- Simple and user-friendly interface.

### 🎯 Project Objective
The main objective of this project is to automate the resume screening process and help recruiters evaluate candidates based on their skills and qualifications.
